Antes de instalar

  1. Obtenha com a Vulcan a URL do manager e a senha de registro do agente.
  2. Garanta saída HTTPS (443) do host até o manager e repositório de atualizações.
  3. Valide o checksum SHA-512 após o download.
  4. Dúvidas ou build macOS: fale com o time.

Implantação

Instalação e registro

Comandos de referência — ajuste hostname, grupo e credenciais conforme o runbook da sua operação.

Validar integridade

Confira o SHA-512 do arquivo baixado antes de instalar em produção.

# Linux
sha512sum vulcan-agent-linux-amd64.deb

# Windows (PowerShell)
Get-FileHash .\vulcan-agent-windows.msi -Algorithm SHA512

Instalar o pacote

Execute com privilégios administrativos no host de destino.

# Debian / Ubuntu
sudo dpkg -i vulcan-agent-linux-amd64.deb

# RHEL / Fedora
sudo rpm -ivh vulcan-agent-linux-x86_64.rpm

# Windows: execute o MSI como Administrador

Registrar no manager

Aponte o agente para o manager Vulcan SIEM e aplique a senha de enrollment.

# Linux — exemplo
sudo vulcan-agent-auth -m MANAGER -p SENHA -G default

# Windows — após instalação, informe manager
# e senha no assistente ou via linha de comando

Operação: após o registro, valide no console do SIEM se o agente aparece como Active. Para ambientes OT convergentes, veja o Vulcan-SIEM OT. ← Voltar à central Business Products
